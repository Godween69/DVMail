# DVMail

Минималистичный веб-клиент для почтового сервера Stalwart (протокол JMAP). Нужны письма и ничего лишнего.

**Статус: рабочая версия.** Веб-клиент и админка ящиков готовы и используются каждый день. Шифрование ящика и вход по QR запланированы, их ещё нет (раздел «Что дальше»).

## Что умеет

- Вход по адресу и паролю приложения, папки со счётчиками, список писем с подгрузкой, поиск.
- Чтение письма: текст и оформленный вид в изолированной рамке, без скриптов и без загрузки внешних картинок.
- Написать, ответить, ответить всем, переслать. Поля «Копия» и «Скрытая», подсказки адресов при наборе.
- Вложения: скачивание, отправка (выбор, перетаскивание, вставка из буфера, до 25 МБ), пересылка вместе с вложениями.
- Тёмная и светлая темы, телефон и планшет, без анимаций при настройке системы «уменьшить движение».
- Отдельная локальная админка: создать ящик, сбросить пароль, удалить ящик (не часть webmail, наружу не публикуется).

Чего нарочно нет: календаря, контактов, чата, лент, внешних сервисов и счётчиков. Письмо считается враждебным, пока не доказано обратное.

## Как устроено

    браузер  ->  HTTPS-прокси (nginx)  ->  контейнер dvmail-web  ->  Stalwart (JMAP)
                                          сервер NestJS + сайт React

- Браузер никогда не обращается к Stalwart напрямую: между ними сервер-посредник.
- Письма на диске клиент не хранит. Пароль приложения живёт только в памяти сервера, зашифрованным.
- Контейнер работает без root, с файловой системой только для чтения и без лишних прав.

Подробно: docs/DESIGN.md (архитектура), docs/WEB.md (как работает веб-клиент), docs/THREAT-MODEL.md (угрозы и аудит).

## Что понадобится

- Почтовый сервер Stalwart 0.16 (ящики на вашем домене, внутренний HTTP-адрес JMAP).
- Сервер с Docker и Docker Compose, домен и сертификат для HTTPS.
- Для разработки и тестов: Node.js 22 и npm (версия записана в .nvmrc), openssl.

## Быстрый старт

Это путь для разработчика: проверить, что код собирается и тесты проходят. Полная установка на сервер с HTTPS описана в docs/DEPLOY.md.

    git clone https://github.com/Godween69/DVMail.git
    cd DVMail
    npm ci
    npm test
    npm run build

Запуск на своём компьютере против вашего Stalwart (без HTTPS, только для проверки):

    STALWART_URL=http://127.0.0.1:8080 \
    ALLOWED_DOMAIN=example.com \
    ALLOWED_ORIGIN=http://127.0.0.1:3000 \
    COOKIE_SECURE=false \
    node apps/server/dist/main.js

После запуска откройте http://127.0.0.1:3000 и войдите ящиком вашего домена. Для двухфакторной защиты нужен пароль приложения (см. docs/WEB.md).

## Устройство репозитория

- apps/server: сервер NestJS (сессии, посредник к Stalwart, отдача сайта).
- apps/web: страница на React и Vite.
- apps/admin: локальная админка ящиков.
- packages/crypto: расшифровка писем S/MIME для будущего шифрования.
- docs: документация. tools: проверка лицензий зависимостей.

Подробности в docs/STRUCTURE.md.
