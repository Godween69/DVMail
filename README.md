# DVMail

Минималистичный веб-клиент для почтового сервера Stalwart (протокол JMAP).

**Статус: в разработке.** Готов этап А: вход, папки, список и чтение писем, вложения, тёмная и светлая темы (docs/WEB.md). Написать письмо, шифрование и QR-вход ещё впереди.

## Идея

- Только письма: папки, список, чтение, написать и ответить, вложения, поиск.
- Никакого календаря, контактов, чата и лент.
- Письмо считается враждебным, пока не доказано обратное.

## Планируется

- Написать и ответить.
- Шифрование ящика: закрытый ключ только у владельца, письма расшифровывает браузер.
- Вход по логину, второму фактору и QR-подтверждению с телефона.

Шифрование и QR-вход пока только запланированы, не реализованы. Показ писем без скриптов и без загрузки внешних картинок (изолированная рамка) уже работает.

## Админка ящиков

Отдельное приложение apps/admin для владельца сервера: создание и удаление почтовых
ящиков в Stalwart. Это не часть webmail и не публикуется наружу: слушает только локальный
адрес и запускается по требованию. Подробности в файле docs/ADMIN.md.

## Технологии

- Серверная часть: NestJS, TypeScript.
- Интерфейс: React, TypeScript, Motion (анимации), DOMPurify (очистка HTML писем).
- Почтовый сервер: Stalwart (JMAP).
