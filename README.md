# DVMail

Минималистичный веб-клиент для почтового сервера Stalwart (протокол JMAP).

**Статус: в разработке.** Готового приложения пока нет, ниже описана цель.

## Идея

- Только письма: папки, список, чтение, написать и ответить, вложения, поиск.
- Никакого календаря, контактов, чата и лент.
- Письмо считается враждебным, пока не доказано обратное.

## Планируется

- Показ писем без скриптов и без загрузки внешних картинок (изолированная рамка).
- Шифрование ящика: закрытый ключ только у владельца, письма расшифровывает браузер.
- Вход по логину, второму фактору и QR-подтверждению с телефона.

Шифрование и QR-вход пока только запланированы, не реализованы.

## Технологии

- Серверная часть: NestJS, TypeScript.
- Интерфейс: React, TypeScript.
- Почтовый сервер: Stalwart (JMAP).
